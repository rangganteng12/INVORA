GALIH & RATNA — SAKURA TWILIGHT
Ready-to-Sell Wedding Invitation Template

Theme: Sakura Twilight — burgundy / plum / blush / champagne / ivory.
Structure and interaction are based on the current master invitation. The theme changes colors, backgrounds and falling decor while preserving the existing page layout and functions.

Included locally:
- assets/cover-bg.png — new AI-generated desktop cover background
- assets/mobile-cover-bg.png — mobile crop of the new background
- assets/section-bg.png — darkened section background derived from the new visual
- assets/location-bg.png — location background crop
- assets/gallery/* — six local demo gallery crops derived from the new visual
- assets/music.mp3 — existing music asset supplied with the template

Customization:
- Replace couple names, dates, venue, account numbers and family names in index.html.
- Replace gallery images inside assets/gallery/.
- Replace assets/music.mp3 only if you have distribution rights for the replacement track.
- RSVP WhatsApp number is configured in script.js.

The stock/demo gallery images from the previous build were converted to local, self-contained demo crops so the package does not depend on remote image URLs.
