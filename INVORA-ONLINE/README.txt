INVORA V9 — BUILT FROM SCRATCH

Open index.html with a local server (VS Code Live Server recommended).

ADDING A NEW THEME:
1. Put the cover image in /assets/.
2. Open themes.js.
3. Add one object to window.INVORA_THEMES.
4. Fill slug, name, collection, category, price, image, tagline, features, story.
5. If a real demo exists, put its relative URL in demoUrl. If demoUrl is empty, the site automatically shows a Preview button instead.
6. No HTML card editing is required. The homepage, filters, search and detail page are generated automatically.

RENAMING SUNDA/JAWA:
Current public names:
- Pusaka Priangan — Sundanese Heritage
- Nusantara Jawi — Central Java Heritage

IMPORTANT:
The current assets include cover previews. Actual invitation demo folders are not bundled here because they were not available as extracted local folders in the workspace. demoUrl is intentionally empty rather than inventing broken links.
