Wedding Passport — Cover Background Only

Perubahan yang dilakukan hanya warna/lapisan background cover pada aturan CSS #cover. HTML, teks, posisi elemen, JavaScript, dan seluruh animasi dipertahankan dari file sumber.

Cara mencoba:
1. Ekstrak ZIP ke folder.
2. Buka folder Wedding-Passport-Background-Only di VS Code.
3. Jalankan index.html dengan Live Server.

Catatan: font dari Google Fonts membutuhkan koneksi internet.
