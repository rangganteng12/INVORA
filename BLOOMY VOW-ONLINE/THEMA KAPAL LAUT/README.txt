GALIH & RATNA — WEDDING INVITATION
=================================

Isi ZIP:
- index.html
- style.css
- script.js
- assets/cover-galih-ratna.jpg
- assets/galih-ratna-original-music.wav (90 detik, musik instrumental original dibuat khusus untuk template)
- assets/stars.png
- assets/gallery/ (6 foto demo original dari artwork yang dibuat khusus untuk template)

CARA MENJALANKAN:
1. Extract ZIP.
2. Buka folder di VS Code.
3. Jalankan dengan Live Server.
4. Buka index.html jika tidak memakai Live Server.

CARA MENGUBAH DATA:
Buka script.js dan edit object CONFIG paling atas:
groom, bride, dateISO, dateText, dateShort, place, address, maps, bank, account, owner, whatsapp.

CATATAN MUSIK:
Musik adalah instrumental sintetis original, bukan potongan lagu pihak lain.
Browser biasanya baru mengizinkan audio setelah user menekan "BUKA UNDANGAN" atau tombol musik.

CATATAN FOTO:
Foto demo di gallery dibuat dari artwork original template ini; tidak mengambil foto pasangan dari internet.
